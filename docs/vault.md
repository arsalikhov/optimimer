# The vault

Tasks, notes, memos and conversation summaries are written as Markdown files with YAML frontmatter under
`VAULT_DIR`. The folder is meant to be an **Obsidian** vault, so every capture shows up on all your devices and can
be queried with **Obsidian Bases** — no plugins needed for the core views.

## Layout

| Folder / file | Contents |
| ------------- | -------- |
| `tasks/` | One file per task: `status`, `priority`, `due`, `category`, `project`, `tags`, `created` … |
| `notes/` | Notes with `category`, `tags`, `status` (inbox / draft / final) |
| `summaries/` | Forwarded-chat summaries and voice memos, transcript included |
| `finance/` | One small note per ledger row (`amount`, `direction`, `category`, `source`, `flagged`) |
| `memory/` | The knowledge graph as wikilinked notes (people, projects, places, facts) |
| `Home.md` | Dashboard embedding one view from each base plus two charts and the task timeline |
| `Tasks.base`, `Notes.base`, `Summaries.base`, `Finances.base`, `Memory.base` | Starter Bases views |
| `Charts.md`, `Gantt.md` | Regenerated by the bot (see below) |

File names are the human title (`tasks/Renew passport.md`); ids stay in frontmatter. Starter files are written only
if missing, so edit them freely. Completing a task flips its `status` to `done`; listing and searching read the same
files, so edits you make in Obsidian are what the bot sees.

## Categories and projects

Every task and note carries a `category` from the fixed list you chose during setup and an optional `project`
nested under it (Fitness → Triathlon, Work → Launch). Titles never repeat the category or project: "make a spec sheet
for the next Work prototype" filed under Work / Prototype becomes "Make a spec sheet". The parsers may create
projects but never categories; the bases group by category, and the timeline uses categories as sections with the
project as a prefix.

## Syncing

Point `VAULT_DIR` at the folder your sync tool keeps on the Pi. With an Obsidian Sync subscription, **Obsidian
Headless** does it without the desktop app: `npm install -g obsidian-headless` (Node 22+), `ob login`,
`ob sync-setup --vault "<remote vault>" --path /opt/optimimer/vault`, then run `ob sync --continuous` as a service.
The installer offers to install that service (`deploy/obsidian-sync.service` is the template). Syncthing or any
file sync works too.

## Dashboard and charts

`Home.md` embeds a view from each base with `![[Tasks.base#Today]]`-style embeds (the Tasks "Board" kanban needs
Obsidian 1.14+), a Mermaid **Gantt** of open tasks by category and project (`Gantt.md`, refreshed every
`GANTT_REFRESH_SECS`), and, if the community **Charts** plugin is installed, `Charts.md`: income vs spending and net
by month, spending by category for the latest month, a stacked six-month category trend, daily spend for the last 30
days, and a Mermaid **Sankey** of the month's money flow (income and transfers in → categories, savings, transfers
out).

## Graph view tips

The `memory/` notes link to each other and to the tasks and notes they mention, so Obsidian's graph shows people,
projects and topics around your files. To hide the noise, exclude `finance/` (one node per transaction) in graph
filters; keep `tasks/` in graph and search so the bot's `recall` and your own searches agree.
